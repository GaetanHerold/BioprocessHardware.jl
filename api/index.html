BioprocessHardware.MockSolressMCU — Type
MockSolressMCU

High-fidelity in-memory simulated SOLRESS ESP32 MCU. Emulates stepper dynamics, AS5600 encoder unwrapping, gentle stall-homing, packet decoding, CRC validation, and 10 Hz telemetry streaming.

BioprocessHardware.channel_put_drop_oldest! — Method
channel_put_drop_oldest!(channel::Channel{T}, item) where T

Thread-safe circular channel write that drops the oldest unread element if the channel is at capacity (Base.n_avail(channel) >= channel.sz_max). Guarantees that put! never blocks the calling thread or task, preventing deadlocks when called while holding locks (such as MockSolressMCU.lock).

BioprocessHardware.load_control_parameters — Method
load_control_parameters(filename::String)

Load control parameters from a JSON file with support for comments and Windows COM port dynamic overrides.

Supports:

  • Single-line comments: // comment or # comment
  • Trailing comments: "key": value // comment
  • Multi-line comments: /* comment */

Returns a Dict{String,Any} with all parameters. Throws error if file does not exist.
