Public API Reference

BioprocessHardware.AbstractActuator — Type
AbstractActuator <: AbstractDevice

A device that accepts setpoints: implements write_setpoint! and safe_state!.

BioprocessHardware.AbstractDevice — Type
AbstractDevice

Root of all instrument types.

BioprocessHardware.AbstractSensor — Type
AbstractSensor <: AbstractDevice

A device that produces measurements: implements read_measurement.

BioprocessHardware.AbstractTransport — Type
AbstractTransport

Byte-level connection to a device. See SerialTransport and MockTransport.

BioprocessHardware.DeviceError — Type
DeviceError

Abstract supertype of every error raised by a BioprocessHardware driver. Catch this to handle any driver failure, or a concrete subtype to be specific.

BioprocessHardware.DeviceFault — Type
DeviceFault(device, code, message)

The device itself reported a fault or rejected a command (for example a Modbus exception response or a firmware ERR reply).

BioprocessHardware.DeviceInfo — Type
DeviceInfo(; vendor, model, serial, firmware, port, driver)

Static identity of a device, recorded in every log header. Unknown fields are empty strings.

BioprocessHardware.DeviceNotConnected — Type
DeviceNotConnected(device)

An operation was attempted on a closed or never-opened device.

BioprocessHardware.DeviceProtocolError — Type
DeviceProtocolError(device, message; raw=nothing)

The device answered, but the answer was malformed, failed a checksum, or did not match the request. raw optionally carries the offending bytes or text.

BioprocessHardware.DeviceTimeout — Type
DeviceTimeout(device, operation, timeout_s)

The device did not answer within timeout_s seconds.

BioprocessHardware.Health — Type
Health(level, reason="")

Result of healthcheck.

BioprocessHardware.HealthLevel — Type
HealthLevel

HEALTH_OK, HEALTH_DEGRADED (working but with warnings) or HEALTH_FAULT.

BioprocessHardware.MockActuator — Type
MockActuator(; name="mock", lo=0.0, hi=100.0, unit="%")

Simulated actuator with a single clamped setpoint. safe_state! sets it to lo. fail_next!(actuator) makes the next write throw; drop_writes!(actuator, true) makes it silently ignore writes (so read-back verification fails, as it would for a stuck device).

BioprocessHardware.MockSensor — Type
MockSensor(; fields=(:signal,), units=(signal="",), generator=nothing, name="mock", info=...)

Simulated sensor. generator(i) (called with the sample index, starting at 1) must return a NamedTuple with the keys in fields; the default produces a smooth sine per field. Use fail_next!(sensor) to make the next read throw a DeviceTimeout, and set_status!(sensor, status) to simulate over/under-range data.

BioprocessHardware.MockTransport — Type
MockTransport(responder=nothing)

In-memory transport for tests and simulators. responder(bytes) is called for every write and may return nothing, a String or Vector{UInt8} that the "device" replies with. Use inject! to push unsolicited bytes (telemetry streams, noise, truncated frames) and t.sent to inspect what the driver wrote.

BioprocessHardware.RateLimiter — Type
RateLimiter(period_s)

ready!(rl) returns true at most once per period_s seconds. Use it to stop a repeating warning (for example ADC saturation) from flooding the logs.

BioprocessHardware.Reading — Type
Reading(value::NamedTuple; units, status=STATUS_OK, source=DeviceInfo(), t_utc=now(UTC))

One measurement. value maps field names to numbers (Float64, NaN when unavailable). units maps the same field names to unit strings (for example "V", "degC").

  • t_utc: UTC wall-clock time of the sample (use for logs and cross-instrument alignment).
  • t_mono_ns: monotonic clock (time_ns()), use it for intervals, it never jumps.
BioprocessHardware.ReadingStatus — Type
ReadingStatus

Quality flag of a Reading: STATUS_OK, STATUS_STALE (older than expected), STATUS_OVERRANGE, STATUS_UNDERRANGE (for example a 4-20 mA loop below 3.6 mA, i.e. broken wire), STATUS_FAULT (device or communication fault, values are NaN).

BioprocessHardware.SerialTransport — Type
SerialTransport(port_name, baudrate; databits=8, parity=SP_PARITY_NONE, stopbits=1)

Transport over a physical serial port (LibSerialPort). Reads are non-blocking: a partial line or a cut cable can never stall the Julia scheduler.

BioprocessHardware.SetpointResult — Type
SetpointResult(ok, requested, applied, attempts, message)

Outcome of write_setpoint!. applied is the value read back from the device (or nothing if the device cannot be read back); ok is false if the write or verification failed.

BioprocessHardware.load_control_parameters — Method
load_control_parameters(filename::String)

Load control parameters from a JSON file with support for comments and Windows COM port dynamic overrides.

Supports:

  • Single-line comments: // comment or # comment
  • Trailing comments: "key": value // comment
  • Multi-line comments: /* comment */

Returns a Dict{String,Any} with all parameters. Throws error if file does not exist.

BioprocessHardware.log_device — Method
log_device(dev; to, every=1.0, n=nothing, duration_s=nothing, stop=Ref(false),
           metadata=Dict(), max_consecutive_errors=10, on_sample=nothing) -> Int

Read dev every every seconds (fixed-rate, no drift) and append the readings to the CSV file to. Stops after n samples, after duration_s seconds, when stop[] becomes true, or on Ctrl-C. Returns the number of rows written.

  • The header block (see write_log_header) is written after the first successful reading.
  • A failed read becomes a row with status STATUS_FAULT and NaN values, so gaps stay visible. After max_consecutive_errors failures in a row the logger throws the last error.
  • on_sample(reading) is called for every successful reading (for live displays).
  • The file is flushed after every row.
BioprocessHardware.probe_ports — Method
probe_ports(probe; baudrate=115200, ports=list_serial_ports(), exclude=String[],
            open_transport=SerialTransport) -> Vector{Pair{String,DeviceInfo}}

Open each candidate port, call probe(transport) and close the port again. probe must perform a read-only identification query and return a DeviceInfo when the expected instrument answered, or nothing otherwise. Errors raised by a probe (timeouts, garbage) mean "not this device" and are logged at debug level.

matches = probe_ports(; baudrate=9600) do t
    try_identify_dpps(t)      # returns DeviceInfo or nothing
end
BioprocessHardware.read_for — Method
read_for(t, duration_s) -> Vector{UInt8}

Collect whatever arrives during duration_s seconds (for devices without a terminator).

BioprocessHardware.read_line — Method
read_line(t; eol="\n", timeout_s=1.0, maxlen=4096, device, operation) -> String

Like read_until but returns the text without the line terminator and without a trailing \r.

BioprocessHardware.read_measurement — Function
read_measurement(sensor) -> Reading

Take one measurement. Throws a DeviceError if the device cannot be read; returns a Reading with a non-STATUS_OK status and NaN values for readable-but-invalid data.

BioprocessHardware.read_measurement — Method
read_measurement(a::MockActuator)

Reading of the current output (:output), so actuators can be logged like sensors.

BioprocessHardware.read_until — Method
read_until(t, terminator; timeout_s=1.0, maxlen=4096, device="device", operation="read") -> Vector{UInt8}

Read from t until terminator (bytes or string) has been received, and return everything read including the terminator. Never blocks beyond timeout_s.

Throws DeviceTimeout when the terminator does not arrive in time and DeviceProtocolError when more than maxlen bytes arrive without it (a runaway or noisy line cannot grow memory without bound).

BioprocessHardware.safe_state! — Function
safe_state!(dev)

Put outputs into their safe state (relay off, pump stopped, valve open, power supply output off, depending on the instrument). Must be idempotent and must not throw if the device is already gone.

BioprocessHardware.save_params_to_json — Method
save_params_to_json(params, filename::String)

Save parameters dictionary to JSON file with pretty formatting.

BioprocessHardware.verified_write — Method
verified_write(write, readback, requested; tol=0.0, retries=2, delay_s=0.05, device="device")

Call write(requested), then readback() and compare with requested (within tol). Retries up to retries extra times. Returns a SetpointResult; does not throw for communication failures, so callers can always inspect result.ok.

Pass readback = nothing for devices that cannot be read back: the result then has applied == nothing and ok == true only if the write itself did not throw.

BioprocessHardware.with_device — Method
with_device(f, dev)

Call f(dev) and always run close_device! afterwards, even if f throws.

with_device(open_dpps("/dev/ttyUSB0")) do dev
    println(read_measurement(dev))
end
BioprocessHardware.with_units — Function
with_units(reading)

Return the reading's values as Unitful quantities. Available after using Unitful (package extension); without Unitful loaded this function has no methods.

BioprocessHardware.write_log_header — Method
write_log_header(io, info::DeviceInfo, units::NamedTuple; metadata=Dict(), started_utc=now(UTC))

Write the commented metadata block of a log file (# key: value lines). Extra metadata entries (calibration constants and dates, operator, experiment id, ...) are written verbatim, one per line, sorted by key.

BioprocessHardware.write_setpoint! — Function
write_setpoint!(actuator, args...) -> SetpointResult
