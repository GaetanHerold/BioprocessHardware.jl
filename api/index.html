BioprocessHardware.MCUTelemetry — Type
struct MCUTelemetry

Container for decoded sensor measurements from the MCU frame.

BioprocessHardware.apply_parameter_defaults! — Method
apply_parameter_defaults!(params::Dict)

Fill in missing parameters with sensible defaults and enforce Float64 numeric types. Modifies params dictionary in-place.

BioprocessHardware.detect_windows_com_ports — Method
detect_windows_com_ports()

Query Windows PnP system via PowerShell to dynamically detect and resolve the COM ports for ESP32 and Numato USB devices, preventing COM port swapping.

BioprocessHardware.flush_telemetry_to_db! — Method
flush_telemetry_to_db!(db, log_stmt, log_buffer::AbstractVector)

Atomically flush telemetry buffer to SQLite database in a single transaction. Clears log_buffer upon successful commit.

BioprocessHardware.format_mcu_actuator_command — Method
format_mcu_actuator_command(current_A::Float64, co2_pct::Float64, pump_pct::Float64)::String

Format setpoints into the standard ASCII serial command recognized by the MCU firmware: PC,<current_A>,<co2_pct>,<pump_pct>\r

BioprocessHardware.init_csv_file — Method
init_csv_file(file_path::String)

Create CSV file and write standardized header row.

BioprocessHardware.init_telemetry_db — Method
init_telemetry_db(db_path::String, experiment_id::String, simulate::Bool)

Initialize SQLite database schema and register current experiment. Auto-recovers from malformed or corrupted database files from prior hard crashes. Returns (db, log_stmt).

BioprocessHardware.insert_params_to_db! — Function
insert_params_to_db!(db, experiment_id::String, p, reset_type="initial")

Record key-value parameters snapshot with timestamp and context label.

BioprocessHardware.is_measurement_line — Method
is_measurement_line(line::String)

Check if a line from the MCU contains a valid timestamp (measurement data). Returns true if line starts with "YYYY-MM-DD HH:MM:SS" pattern.

BioprocessHardware.load_control_parameters — Method
load_control_parameters(filename::String)

Load control parameters from a JSON file with support for comments and Windows COM port dynamic overrides.

Supports:

  • Single-line comments: // comment or # comment
  • Trailing comments: "key": value // comment
  • Multi-line comments: /* comment */

Returns a Dict{String,Any} with all parameters. Throws error if file does not exist.

BioprocessHardware.parse_mcu_line — Function
parse_mcu_line(line::String, use_new_unit::Bool=true)

Parse comma-separated telemetry frame received from the MCU: Format: DTM,pH1,pH2,PS(V),PS(A),LVL1(%),LVL2(%),LVL3(%),LVL4(%),T(°C),DOS set(%),FLO set(%),lim. volt.(V),fixed curr.(A),...

Returns MCUTelemetry on success, or nothing if corrupted/incomplete.

BioprocessHardware.read_numato_adc — Function
read_numato_adc(sp::SerialPort, channel::Int=0)::Float64

Send adc read <channel>\r command and parse the 10-bit integer count [0..1023]. Returns NaN on read failure.

BioprocessHardware.run_bioflo_monitor_task! — Method
run_bioflo_monitor_task!(keep_running, params, conn, latest_bioflo_data_ref)

Background async task that periodically polls the BioFlo Modbus server for pH, Temp, and dCO2.

BioprocessHardware.run_bioflo_pwm_task! — Method
run_bioflo_pwm_task!(duty_ref, keep_running, params, conn; window_ref, min_on_ref, min_off_ref)

Background async task for continuous slow PWM on the BioFlo Pumps 1 and 3 via Modbus TCP.

BioprocessHardware.run_mock_pump2_task! — Method
run_mock_pump2_task!(keep_running, params, conn)

Mock fermentation Pump 2 routine: sets Pump 2 (loop 7, address 78) to 5.0 ml/min for 30 seconds every 5 minutes (300 seconds), and 0.0 ml/min for the rest of the cycle.

BioprocessHardware.run_yocto_monitor_task! — Method
run_yocto_monitor_task!(keep_running, params, latest_yocto_data_ref; project_root)

Background async task that reads the latest calibrated dissolved CO2 measurement from the Yoctopuce 4-20mA bridge (plots/yoctoco2live.json) and launches the bridge daemon if needed.
